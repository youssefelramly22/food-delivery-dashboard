# Food Delivery Dashboard

An interactive Food Delivery Dashboard built with Python, Pandas, Plotly, and Streamlit.

## Project Overview

This project analyzes food delivery orders to identify patterns and relationships affecting delivery performance.

The dataset contains 45,593 orders and 20 columns.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Jupyter Notebook

## Dashboard Features

- Order volume analysis
- Delivery time analysis
- Traffic and weather analysis
- Vehicle performance analysis
- Delivery distance analysis
- Trends and relationships
- Delivery person performance
- Interactive filters

## Key Insights

- Higher traffic density is associated with longer delivery times.
- Multiple deliveries are associated with higher delivery times.
- Delivery distance shows a relationship with delivery time.
- The dataset contains a noticeable gap in recorded dates between February 18 and March 1.
- The number of distinct restaurant coordinates increased after March 1, indicating an increase in represented restaurants.
- Delivery activity shows different recorded time coverage across days, contributing to the alternating pattern in daily order counts.
